# SVPlayer

SVPlayer 是一款面向 iPhone、iPad、Mac 和 Apple TV 的私人影院播放器，支持 Emby、Jellyfin、Plex、NAS、网盘与 IPTV。
SVPlayer is a private cinema player for iPhone, iPad, Mac and Apple TV, with Emby, Jellyfin, Plex, NAS, cloud drives and IPTV.
